# 화면 목록

> 피그마에서 그릴 화면입니다. 파일: [실버케어 화면](https://www.figma.com/design/eOm90ve0gRyfLPEJHsByvt). 프레임을 만들면 아래 표의 "피그마" 칸에 링크를 적습니다.
> 색과 글씨 크기는 파일의 `실버케어` 변수 모음에, 말풍선·큰 버튼·듣는 중 표시는 `컴포넌트` 섹션에 있습니다.
> 화면이 기준이고 코드는 화면을 따라갑니다 ([DIRECTION.md](./DIRECTION.md) 5절).
> 이 문서는 **화면 목록**(무엇이 있나)입니다. 화면마다의 세부(영역, 요소, 다섯 가지 모습, 동작, 문구)는 `specs/` 3층 화면 명세가 [templates/screen.md](./specs/templates/screen.md) 틀로 정합니다.

## 공통

- 색과 글씨 크기는 피그마의 변수(Variables)로 정하면 코드가 그대로 가져다 씁니다.
- 어르신 화면은 글씨 최소 32pt, 버튼은 손바닥 크기, 한 화면에 할 일 하나. 로그인·설정·뒤로 가기는 없음.
- 모든 화면은 기본, 불러오는 중, 비어 있음, 오류, 연결 끊김 다섯 가지 모습을 함께 그립니다 (DR-UI-01).
