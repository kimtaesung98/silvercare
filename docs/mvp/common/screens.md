# 공통 MVP: 기본 화면

> 기능 화면을 정할 때 이 목록을 훑어 빠진 기본 화면이 없는지 확인합니다 ([README.md](../README.md) 4.2절).
> 화면마다 세부는 [templates/screen.md](./templates/screen.md) 틀로 씁니다.

| 화면 | 꼭 있어야 할 것 | 요구사항 |
| --- | --- | --- |
| 처음 실행 안내 | 이 앱이 무엇인지 한 줄, 다음에 할 일 하나 | MVP-C-06 |
| 약관·개인정보 동의 | 동의 항목, 전문 보기, 동의 버튼 | MVP-C-09 |
| 권한 안내 | 권한마다 왜 필요한지, "허용"과 "나중에" | MVP-C-05 |
| 로그인 | 입력 칸, 로그인 버튼, 틀렸을 때 안내, 문의 길 | MVP-C-01 |
| 내 정보 | 이름, 소속, 연결된 대상 | MVP-C-03 |
| 설정 | 알림 켜고 끄기, 약관 다시 보기, 문의, 앱 버전, 로그아웃 | MVP-C-04, 09, 10 |
| 로그아웃 확인 | "정말 나갈까요?"와 두 버튼 | MVP-C-02, MVP-UI-08 |
| 연결 끊김 | 어느 화면 위에나 뜨는 띠. 다시 이으면 사라짐 | MVP-C-07 |
| 오류 | 무엇이 안 됐고 무엇을 하면 되는지, "다시 하기" | MVP-C-07 |
| 알림에서 들어온 화면 | 알림 내용과 그 다음 할 일 | MVP-C-08 |

모든 화면에는 다섯 가지 모습(기본, 불러오는 중, 비어 있음, 오류, 연결 끊김)이 있습니다 (MVP-UI-01).
