# 공통 MVP: 요구사항

> 어느 프로젝트에나 쓰는 기본기입니다. 프로젝트 이름을 쓰지 않습니다.
> 강도는 반드시 · 되도록 · 해도 됨. 프로젝트는 이 표에서 고르고, 바꾼 점은 자기 `mvp.md`의 들여오기 표에 적습니다.

## 1. 기본 기능 (MVP-C)

| 번호 | 강도 | 무엇 | 수락 기준 |
| --- | --- | --- | --- |
| MVP-C-01 | 반드시 | **로그인**: 사람마다 확인된 길로 들어온다. 한 번 들어오면 앱을 다시 열어도 묻지 않는다 | 로그인 뒤 앱을 껐다 켜도 첫 화면으로 바로 간다. 틀리면 무엇이 틀렸는지 보인다 |
| MVP-C-02 | 반드시 | **로그아웃**: 언제든 나갈 수 있고, 나가면 기기에 남은 로그인 정보가 지워진다 | 로그아웃 뒤 뒤로 가기로 이전 화면에 갈 수 없다 |
| MVP-C-03 | 반드시 | **내 정보**: 내가 누구로 들어와 있는지(이름, 소속, 연결된 대상) 본다 | 내 정보 화면에 이름과 소속이 보인다 |
| MVP-C-04 | 반드시 | **설정**: 알림 켜고 끄기, 로그아웃, 앱 버전이 한 화면에 있다 | 알림을 끄면 다음 알림부터 오지 않는다 |
| MVP-C-05 | 반드시 | **권한 안내**: 마이크·위치·알림 같은 권한을 묻기 전에 왜 필요한지 먼저 보여 주고, 거절해도 앱이 멈추지 않는다 | 권한을 거절하면 그 기능만 꺼지고, 다시 켜는 길이 보인다 |
| MVP-C-06 | 반드시 | **처음 실행**: 처음 켠 사람이 다음에 무엇을 할지 안다 (로그인, 기기 등록, 권한) | 새 기기에서 안내만 따라 첫 화면까지 간다 |
| MVP-C-07 | 반드시 | **오류와 연결 끊김**: 서버나 네트워크가 안 될 때 무엇이 안 됐고 무엇을 하면 되는지 보이고, 다시 되면 저절로 돌아온다 | 네트워크를 끊으면 연결 끊김 표시, 다시 이으면 표시가 사라지고 하던 일이 이어진다 |
| MVP-C-08 | 반드시 | **알림 받기**: 앱이 닫혀 있어도 중요한 알림이 오고, 누르면 그 내용 화면으로 간다 | 앱을 닫고 알림을 보내면 오고, 누르면 해당 화면이 열린다 |
| MVP-C-09 | 되도록 | **약관과 개인정보 동의**: 처음 쓸 때 동의를 받고, 설정에서 다시 볼 수 있다 | 동의하지 않으면 개인정보를 쓰는 기능이 시작되지 않는다 |
| MVP-C-10 | 되도록 | **문의와 도움말**: 막혔을 때 누구에게 어떻게 묻는지 설정에 있다 | 설정에 연락처가 보인다 |
| MVP-C-11 | 되도록 | **기록**: 오류와 중요한 동작(로그인, 알림 받음)이 서버 기록에 남되, 개인정보는 남기지 않는다 | 오류를 일으키면 기록에 남고, 기록에 대화 원문·비밀번호가 없다 |
| MVP-C-12 | 해도 됨 | **계정 지우기**: 사용자가 자기 정보를 지워 달라고 할 수 있다 | 지운 뒤 같은 계정으로 들어올 수 없다 |

## 2. 화면 규칙 (MVP-UI)

모든 화면(공통이든 고유든)이 지킵니다.

| 번호 | 강도 | 지킬 것 | 확인 |
| --- | --- | --- | --- |
| MVP-UI-01 | 반드시 | 모든 화면은 **다섯 가지 모습**을 명세하고 그린다: 기본, 불러오는 중, 비어 있음, 오류, 연결 끊김 | 피그마에 다섯 프레임, 모습마다 위젯 테스트 |
| MVP-UI-02 | 반드시 | 색 · 글씨 크기 · 간격 · 둥글기는 디자인 변수 이름으로만 쓴다 | 코드에 색·크기 숫자가 없는지 검사 |
| MVP-UI-03 | 반드시 | 반복되는 요소(버튼, 입력 칸, 목록 줄, 알림 띠, 대화 상자)는 디자인 컴포넌트 하나와 코드 부품 하나가 짝이다 | 짝 표 |
| MVP-UI-04 | 반드시 | 화면에 보이는 모든 문구는 명세의 문구 표에 있다. 오류 문구는 "무엇이 안 됐고, 무엇을 하면 되는지" | 문구 표와 화면 대조 |
| MVP-UI-05 | 반드시 | 누르는 곳 최소 48dp, 글씨 최소 16pt, 글자와 배경 대비 4.5:1 이상 (WCAG 2.1 AA). 프로젝트가 더 크게 정할 수 있다 | 자동 검사 |
| MVP-UI-06 | 반드시 | 무언가 기다리게 하면 1초 안에 기다리는 중임을 보여 준다 | 느린 가짜 서버로 테스트 |
| MVP-UI-07 | 되도록 | 앱마다 화면 지도 한 장(어느 화면에서 무엇을 하면 어디로)을 둔다 | 지도와 코드의 경로 대조 |
| MVP-UI-08 | 되도록 | 되돌릴 수 없는 동작(로그아웃, 지우기)은 한 번 더 묻는다 | 위젯 테스트 |
