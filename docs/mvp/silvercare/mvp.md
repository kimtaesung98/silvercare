# 실버케어 MVP

> 상태: 초안 · 고친 날: 2026-10-20 · 주인 확인 필요
> 고유 MVP는 [../../specs/requirements.md](../../specs/requirements.md)의 사용자·개발자 요구사항으로 풀어 씁니다. 공통 MVP는 [../common/](../common/requirements.md)에서 들여옵니다.

## 1. 한 문장

> 보호자가 태블릿을 켜 말동무를 맡겨 두고 떠나면, 어르신은 움직이는 마이크에 말을 걸기만 하고, 말동무가 곧바로 대답하며, 위급한 말은 이동 중인 조무사에게 바로 전해지고, 조무사는 도착할 때 짧은 브리핑을 받는다.

## 2. 고유 MVP 범위

| 묶음 | 들어가는 것 | 요구사항 |
| --- | --- | --- |
| 맡겨 두기 (보호자) | 보호자가 태블릿에서 처음 설정, 시작, 상태 보기, 멈추기. 그 뒤엔 손대지 않아도 돎 | UR-G-05 |
| 말동무 대화 | 말로 시작, 곧바로 맞장구, 움직이는 마이크(대화 글 없음), 그만하기 | UR-E-01~03, 06, 07 · DR-PERF-01~02 |
| 위급 | 규칙 필터 먼저, 안심 문장, 조무사에게 바로 알림 | UR-E-04, UR-C-02 · DR-SAFE-01~04 |
| 픽업 대기 | 오늘 방문, 출발하기, 도착 임박 안내, 도착 브리핑 | UR-E-05, UR-C-01, 03 |

## 3. MVP 밖 (다음으로)

| 무엇 | 이유 |
| --- | --- |
| 보호자 휴대폰 앱 (UR-G-01~04) | 보호자는 태블릿에서 조작함 (UR-G-05). 원격 알림과 하루 소식은 그다음 |
| 채팅식 대화 화면 | 주인 결정: 어르신 화면은 움직이는 마이크만 |
| 하루 소식, 안부 대화 시각 | 보호자 앱과 함께 |
| 센터 기록 (UR-O-01) | 쌓인 대화가 있어야 의미가 있음 |
| 끼어들기 (UR-E-08) | 에코 제거가 확실한 기기에서만 켜는 기능 (결정 22) |
| 이동 중 대화 미리 보기 (UR-C-04) | 알림과 브리핑으로 MVP 목적에 닿음 |

## 4. 공통 MVP 들여오기

앱은 어르신 태블릿과 조무사 휴대폰 둘입니다. 태블릿에는 **보호자 화면**(조작)과 **어르신 화면**(움직이는 마이크) 두 쪽이 있습니다.

| 공통 | 어르신 태블릿 | 조무사 앱 | 바꾼 점과 이유 |
| --- | --- | --- | --- |
| MVP-C-01 로그인 | 바꿔서 | 바꿔서 | 태블릿: 어르신 로그인 없이 **기기 토큰**으로 들어오고, 보호자 화면만 보호자 확인을 거침 (원칙 2, 결정 20, 열린 질문 Q-2). 조무사: 센터가 준 아이디·비밀번호 (결정 14, 열린 질문 Q-1) |
| MVP-C-02 로그아웃 | 안 씀 | 그대로 | 태블릿은 어르신이 나갈 일이 없음 |
| MVP-C-03 내 정보 | 안 씀 | 그대로 | 조무사: 이름, 센터 |
| MVP-C-04 설정 | 바꿔서 | 그대로 | 태블릿 설정은 **보호자 화면**에 있음 (주인 결정). 어르신 화면에는 설정·뒤로 가기 없음 |
| MVP-C-05 권한 안내 | 바꿔서 | 그대로 | 태블릿: 마이크 권한은 보호자가 처음 설정 때 허용. 어르신에게 묻지 않음 |
| MVP-C-06 처음 실행 | 바꿔서 | 그대로 | 태블릿: 보호자가 하는 처음 설정 = 기기 연결, 마이크 허용, 소리 시험 |
| MVP-C-07 오류·연결 끊김 | 바꿔서 | 그대로 | 태블릿: 오류 문구 대신 "잠시만요, 다시 이어 볼게요" 같은 말과 소리. 어르신이 할 일은 없음 (원칙 2) |
| MVP-C-08 알림 받기 | 안 씀 | 그대로 | 위급 알림이 MVP의 핵심 (UR-C-02) |
| MVP-C-09 약관·동의 | 바꿔서 | 그대로 | 어르신 동의는 센터 등록 때 종이로 받는다고 가정 (열린 질문 Q-3) |
| MVP-C-10 문의 | 안 씀 | 그대로 | |
| MVP-C-11 기록 | 그대로 | 그대로 | 대화 원문은 기록에 남기지 않음 (원칙 6) |
| MVP-C-12 계정 지우기 | 안 씀 | 안 씀 | 센터가 계정을 만들고 지움 |
| MVP-UI-01~08 화면 규칙 | 바꿔서 | 그대로 | 어르신 화면은 글씨 최소 32pt, 버튼은 손바닥 크기, 한 화면에 할 일 하나 (`../../screens.md` 공통) |

## 5. 화면

고유 화면은 [../../screens.md](../../screens.md)에 있습니다. 위 표에서 "그대로"나 "바꿔서"인 공통 화면은 이 프로젝트에서 이렇게 생깁니다.

| 앱 | 공통에서 온 화면 |
| --- | --- |
| 어르신 태블릿 | 보호자 화면: 처음 설정(기기 연결 · 마이크 허용 · 소리 시험), 맡겨 두기와 멈추기, 오늘 상태. 어르신 화면: 연결 끊김 안내(말과 마이크 모양) |
| 조무사 앱 | 처음 실행, 권한 안내(위치·알림), 로그인, 내 정보, 설정, 로그아웃 확인, 연결 끊김, 오류, 위급 알림에서 들어온 화면 |

## 6. 끝났다고 볼 기준

1. 2절의 요구사항과 4절에서 들여온 공통 항목의 수락 기준이 모두 자동 테스트로 통과한다.
2. 실제 Android 태블릿과 휴대폰 한 대씩으로, 키 없이 한 번, 키를 넣고 한 번 아래 장면을 돌린다: 보호자가 태블릿을 맡겨 두고 떠남 → 조무사 로그인 → 출발 → 어르신이 말을 걸고 대화 → 위급한 말 → 조무사 알림 → 도착 임박 안내 → 도착 브리핑.
3. 주인이 그 장면을 직접 돌려 본다.
