# 중위 명세: 음성

> 층: 모듈 · 상태: 초안 · 고친 날: 2026-10-21
> 위층: UR-E-01, UR-E-02, UR-E-03, UR-E-06, UR-E-08, DR-PERF-01~02, DR-ARCH-04~05, DR-PRIV-01, DR-FALL-02~03, DR-QA-03 ([requirements.md](../requirements.md))

## 1. 목적

어르신은 화면을 만지지 않고 말로만 대화합니다 (북극성 "말을 걸면 곧바로 따뜻한 목소리가 대답"). 음성 묶음은 태블릿에서 **어르신의 말을 듣고(귀)**, 대화방에 오는 **다른 참가자의 말을 소리로 들려주는(입)** 일을 맡습니다. 듣고 말하는 상태를 마이크 원 하나로 보여 줄 수 있게 상태를 내보냅니다.

## 2. 경계

- 한다: 마이크 열고 닫기, 말이 시작되고 끝나는 때 찾기, 들은 말을 글(기기 인식) 또는 말 구간 소리(서버 인식)로 내보내기, 받은 글이나 소리를 순서대로 들려주기, 말하는 동안 듣기 멈추기, 귀와 입의 상태 내보내기.
- 하지 않는다:
  - 위급 판단 → `mid/safety` (서버). 음성 묶음은 들은 말을 거르지 않고 그대로 넘깁니다 (DR-SAFE-04).
  - 무엇을 대답할지 → `mid/companion` (서버).
  - 대화방에 보내고 받기 → `mid/chat-core`와 태블릿 앱(`mid/elder-tablet`)의 대화 흐름.
  - 화면 그리기 → `mid/elder-tablet`. 음성 묶음은 상태만 내보냅니다.
  - 서버 음성 서비스 키 보관 → 서버 (DR-ARCH-04). 태블릿에는 키가 없습니다.

## 3. 지키는 원칙

| 원칙 | 여기서 뜻하는 것 |
| --- | --- |
| 1 안전이 먼저 | 들은 말은 하나도 버리지 않고 넘깁니다. "잡음 같다"는 이유로 거르는 일은 길이 기준(0.4초 미만)만 허용합니다 |
| 2 어르신 눈높이 | 기계를 만질 일이 없습니다. 말이 끝나면 곧바로 소리가 납니다 (0번 문장은 `mid/companion`이 고르고, 음성 묶음은 바로 틉니다) |
| 4 Claude는 서버에서만 | 서버 음성 인식·합성도 서버에서 부릅니다. 태블릿은 소리 구간을 보내고 소리를 받기만 합니다 |
| 5 키가 없어도 돈다 | 서버 음성이 없으면 기기 내장 인식과 읽어 주기로 바꿉니다 |
| 6 개인정보 조심 | 대화방이 열리기 전에는 듣지 않습니다. 들은 소리를 기기에 저장하지 않습니다 |

## 6. 흐름

한 턴 (기기 인식 방식, 지금 `v2/apps/elder_tablet`이 쓰는 방식):

1. 보호자가 "켜 두고 나가기"를 누르면 대화방이 열리고, 그다음 듣기가 듣기 시작합니다. 마이크 원: 기다림.
2. 어르신이 말을 시작하면 듣기가 "말이 들림"을 알립니다. 마이크 원: 듣는 중.
3. 말이 끝나면(무음 기준) 듣기가 들은 글을 내보냅니다. 대화 흐름이 대화방에 보냅니다.
4. 대화방에 말동무나 안전 지킴이의 말이 오면 듣기를 멈추고 재생 순서가 들려줍니다. 마이크 원: 말하는 중.
5. 다 들려주면 다시 1의 듣기로 돌아갑니다.

서버 인식 방식은 3에서 글 대신 소리 구간을 보내고, 서버가 글로 바꿔 대화방에 넣습니다.

## 8. 수락 기준

| 번호 | 상황 (Given) | 행동 (When) | 결과 (Then) |
| --- | --- | --- | --- |
| AC-V-01 | 보호자 화면이다 | 어르신이 말한다 | 듣기가 아무것도 내보내지 않고 마이크가 닫혀 있다. "켜 두고 나가기" 뒤에는 듣는다 |

| AC-V-04 | 말동무 소리가 나는 중이다 | 스피커 소리가 마이크에 들어간다 | 듣기는 아무것도 내보내지 않는다 |
