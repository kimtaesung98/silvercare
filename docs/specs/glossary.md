# 용어집

> 명세는 이 뜻으로만 씁니다. 새 말이 필요하면 여기에 먼저 더합니다.

| 말 | 뜻 | 코드 이름 |
| --- | --- | --- |
| 바탕 | 대화방 · 참가자 · 메시지 · 실시간 전달만 하는 층. 서비스 내용을 모름 | `chat` |
| 대화방(방) | 참가자들이 메시지를 주고받는 곳 하나 | room |
| 참가자 | 방에 들어와 메시지를 읽고 쓰는 사람 또는 AI | `Participant` |
| 메시지 | 방에 오가는 말 한 덩이. 보낸 사람, 글, 표시를 가짐 | `Message` |
| 표시 | 모듈이 메시지에 붙이는 꼬리표 (예: 위급) | `Tags` |
| 모듈 | 방의 메시지를 보고 끼어들거나 덧붙이는 부품. 켜고 끌 수 있음 | `Module` |
| 서비스 | 언제 어떤 방을 열고 누구를 넣을지 정하는 규칙 | |
| 말동무 | 어르신과 이야기하는 AI 참가자 | `companion` |
| 안전 지킴이 | 위급 표시를 보고 안심 문장을 보내는 참가자 | `safety.Guard` |
| 규칙 필터 | 정해진 낱말과 활용형으로 위급을 찾는 부분. Claude보다 먼저 | `safety` rules |
| 위급 | 규칙 필터나 AI가 사람이 곧 알아야 한다고 판단한 말 | |
| 안심 문장 | 위급일 때 말동무 대신 나가는 정해진 말 | |
| 턴 | 어르신 말 하나와 그에 대한 말동무 대답 하나 | |
| 0번 문장 | 어르신 말이 끝나자마자 트는, 미리 받아 둔 짧은 맞장구 소리 | opener |
| 추임새 | 대답이 늦을 때 한 번 넣는 짧은 말 ("음, 그러셨구나") | filler |
| 대체 동작 | 외부 서비스가 없거나 실패할 때 대신 하는 동작 | fallback |
| 말 구간 | 녹음에서 말이 시작해 끝날 때까지 자른 한 덩이 | utterance |
| 배경 소리 | 말이 없을 때 들리는 소리의 세기 | noise floor |
| 소리 세기 | 소리 조각의 크기를 0~1로 잰 값 (RMS) | level |
| 끼어들기 | 말동무가 말하는 중에 어르신이 말하는 것 | barge-in |
| 픽업 대기 | 조무사가 출발해 도착할 때까지 어르신 곁을 지키는 서비스 | pickup |
| 남은 시간 | 조무사가 도착하기까지 걸릴 것으로 보는 시간 | ETA |
| 브리핑 | 조무사가 도착할 때 받는 어르신 상태 요약 | briefing |
| 하루 소식 | 보호자에게 가는 하루 대화 요약 | daily digest |
| 가짜 부품 | 테스트에서 진짜 기기 기능 대신 끼우는 부품 | fake |
| 쌍둥이 시험 | 서로 모르는 에이전트 둘이 같은 명세로 따로 만들어 결과를 비교하는 시험 | |
| 가정 | 명세를 쓰는 쪽이 스스로 정한 값. 근거와 함께 표시 | |
| 열린 질문 | 명세가 정하지 못해 주인에게 묻는 것. 만드는 쪽이 혼자 정하면 안 됨 | |
